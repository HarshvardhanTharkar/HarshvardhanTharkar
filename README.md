## Engineering Principles
Separation of concerns   →  Controller · Service · Repository pattern

Infrastructure as code   →  Everything reproducible from Terraform state

Security in the pipeline →  Scan before you push, not after you deploy

Test before you merge    →  Unit tests gate the build; broken pipelines don't deploy

Config over code         →  Environment variables, never hardcoded secrets
